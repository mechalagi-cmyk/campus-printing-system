# PrintU
PrintU is a campus printing management system designed to simplify the document printing process for university students.

### Project Information
- Project Name: PrintU
- Course: ISAPMD
- Project Path: Path B
- Team Size: 5 Members
- Platform: To be determined

### Project Objectives
- Simplify the printing order process.
- Enable students to submit documents online.
- Help printing staff manage incoming orders.
- Allow students to monitor their printing order status.

### Development Status
Project initiation and Sprint 1 preparation.
